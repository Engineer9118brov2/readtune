# ReadTune marketing media slots

Drop real product media into this folder using these reserved names. After adding an asset, also add its filename to `media.json`; `site.js` then replaces the designed placeholder without probing missing files in production.

## Screenshots
- `calibration-results.png` — result screen with signal + provisional language
- `reader-settings.png` — Reader View with the polished settings rail
- `reading-lab.png` — repeatability / recent runs / Voice Fit
- `read-aloud.png` — fallback still for the read-aloud video slot
- `restyle-page.png` — fallback still for the live-restyle video slot

## Videos
- `ai-mode.mp4` — **priority**: Article chat workflow beside a real article
- `read-aloud.mp4` — sentence + word highlighting and transport controls
- `restyle-page.mp4` — before/after live-page restyling

For video, aim for 12–20 seconds, 16:10 or 16:9, muted-friendly, and under ~8 MB
when possible. The site autoplays muted unless the visitor requests reduced
motion; normal video controls remain available.

Detailed shot-by-shot capture instructions live in [`VIDEO_BRIEF.md`](VIDEO_BRIEF.md).
